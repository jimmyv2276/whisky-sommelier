# whisky-sommelier
AI Club project to create a whiskey sommelier chatbot
### 🔑 How to use this locally in VS Code:

1. Install `python-dotenv` by adding it to your `requirements.txt`.
2. Create a file named `.env` in the root of your project directory.
3. Add your OpenAI API key inside that file:
   ```env
   OPENAI_API_KEY=your-actual-api-key-here
   ```
4. Add `.env` to your `.gitignore` file so you never accidentally commit your private keys to GitHub!
